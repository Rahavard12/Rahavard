# رهاورد — وبلاگ شخصی

این نسخه برای وبلاگ شخصی «رهاورد» شخصی‌سازی اولیه شده است:

- فارسی و راست‌چین
- فونت Vazirmatn
- عنوان و توضیحات فارسی
- منوی ساده: خانه، نوشته‌ها، درباره من
- حذف فرم خبرنامه پیش‌فرض
- حفظ حالت روشن/تاریک
- آماده برای افزودن نوشته‌های شخصی

## افزودن نوشته
نوشته‌های وبلاگ را در پوشه `data/blog` قرار دهید. قالب اصلی از Markdown/MDX پشتیبانی می‌کند.

## قبل از انتشار
در `data/siteMetadata.js` مقدار `siteUrl` را با دامنه واقعی سایت جایگزین کنید و اطلاعات شبکه‌های اجتماعی را تنظیم کنید.
